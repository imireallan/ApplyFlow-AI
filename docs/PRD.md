## Project Overview

**`ApplyFlow AI`** is a smart job-tracking system designed to solve "application fatigue" and improve submission quality through AI-driven insights.

### Core Features:

- **AI Match Scoring**: Semantic analysis of a job description against the applicant's resume (CV.pdf) to generate a percentage-based compatibility score.

- **Dynamic Target Tracking**: A dashboard to monitor weekly application goals (e.g., 5/week), with automated reminders for falling behind.

- **Unified Dashboard**: Built with `React Router v7`, utilizing `loaders` for instant data availability and `actions` for high-performance job state mutations.
