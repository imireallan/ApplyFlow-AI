# Merge + Recovery — ApplyFlow AI

Merge queue: re-run checks on latest main.
Feature flags: new changes behind flag; internal-first use.
Release: latest channel first; stable trails.
Rollback: one-step revert; broken builds reverted; flags turn off quickly.
Watch: author + on-call watch; fix-forward or rollback.
Incidents/reverts feed back into reviewer eval set.
