### Data Models (PostgreSQL):

#### 1. **User Model**
This model handles authentication and the high-level goals that drive the automated reminders.

   - id: UUID (Primary Key).

   - email: String (Unique) — Used for notifications and login.
    - full_name: String.

   - weekly_target: Integer (Default: 5) — The application goal the "Nudger" service monitors.

   - timezone: String — To ensure reminders are sent at appropriate local times.

   - created_at: Timestamp.

#### 2. **Job Application Model**
It stores metadata for every role applied to and links to the AI's evaluation.

   - id: UUID (Primary Key).

   - user_id: UUID (Foreign Key) — Links the job to a specific user.

   - company_name: String.

   - job_title: String.

   - status: Enum — READY_TO_APPLY, APPLIED, INTERVIEWING, OFFER, REJECTED.

   - job_description_text: Text — Raw text used for AI analysis.

   - ai_match_score: Float — The compatibility score generated by the LangChain service.

   - application_url: String.

   - deadline: Timestamp — Used by the Nudger to send "Closing Soon" alerts.

   - created_at: Timestamp.

#### 3. **AI Insights Model (One-to-One with Job)**
Separating detailed AI reasoning into its own model to keeps the main Job table performant while storing deep context from the LLM.

   - job_id: UUID (Foreign Key / Unique).

   - missing_skills: JSONB — A list of skills found in the JD but missing from your CV (e.g., "Redis", "GraphQL").

   - suggested_highlights: Text — 3 key points from an applicant experience (eg GCP serverless pipeline work) that the applicant should mention in the interview.

   - tailored_pitch: Text — An AI-generated summary for the applicant cover letter or LinkedIn reach-out.

#### 4. **Application Target Logs**
This is a "heartbeat" table used by the Node.js Nudger to calculate progress without re-scanning the entire Jobs table every hour.

   - id: UUID.

   - user_id: UUID.

   - week_number: Integer (1-52).

   - year: Integer.

   - current_count: Integer — Number of applications submitted in a week.

   - target_reached: Boolean.

### React Router v7 Contract:

- **Loader Pattern:** The jobs route loader pre-calls the FastAPI /analyze endpoint to fetch the AI score before the component mounts.

- **Action Pattern:** Form submissions to update a job's status are handled via actions, ensuring the UI stays synchronized with the database.
